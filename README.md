# Intelligent Crowd Behavior Prediction System (ICBPS)

A React + Vite + TypeScript + Tailwind CSS frontend for crowd behavior prediction and monitoring.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite 5** (build tool)
- **Tailwind CSS v3** (styling)
- **Lucide React** (icons)

## Setup & Run

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## Login

Use any username + any password to log in (demo/prototype — no backend auth).

## Features

- **Dashboard** — Real-time crowd density metrics & chart
- **Media Ingestion** — Upload or select preset surveillance video
- **Telemetry Analysis** — Canvas-based animated crowd simulation with HUD overlays
- **Behavior Forecasts** — Interactive Markov flow simulator with sliders
- **Operation Logs** — Searchable/filterable audit log with pagination
- **System Settings** — Alert thresholds, model parameters, display preferences
